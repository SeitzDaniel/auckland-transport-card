# Auckland Transport Card

## 📢 Standalone Card Repository – Deprecation

The standalone card repository will no longer receive updates and will eventually be archived.

### Integrated Lovelace Card

The Auckland Transport Card has been merged into the [Auckland Transport Integration](https://github.com/SeitzDaniel/auckland_transport).

**Benefits:**
- One repository for both integration and card.
- The card is automatically installed with the integration.
- Simplified installation, updates and maintenance.

**For new installations and future updates, please use the integrated version.**
